## Core Adapter Requirements for T-05

1. **Per-Field Confidence Self-Assessment**:
   Teammate's single global `confidence` cannot be copied to the four canonical fields, and synthesizing scores or defaulting to `0.5` is prohibited. The T-05 extraction prompt must instruct Gemini to output four specific self-assessment floats: `restaurant`, `priceCad`, `hours`, and `expiresOn`.
2. **Rejection Policy (Tentative Suggestions Allowed)**:
   Arbitrary global confidence rejection thresholds must not be preserved. Tentative autocomplete suggestions are permitted for partially clear offers. `isDeal: false` is reserved strictly for actual evidence that no offer exists. Low confidence alone routes to the editable review form for human confirmation.
3. **Forbidden Instagram URL-Context**:
   Teammate's `tools: [{ url_context: {} }]` must NOT be executed on Instagram URLs. Instagram posts must enter the pipeline via uploaded screenshot bytes or user-transcribed text. `sourceUrl` is stored on the `deals` table as reference provenance and is not an argument to `extractDeal`.
4. **Model Name Verification**:
   The primary documentation at `https://ai.google.dev/gemini-api/docs/models` confirms `gemini-3.8-flash` and `gemini-3.5-flash-lite` as official stable models.
5. **CAD Currency Enforcement**:
   CAD requires explicit supplied currency evidence; Vancouver context plus a dollar sign does not prove CAD. Non-CAD or ambiguous dollar amounts must result in `priceCad: null`. Conditions must contain only source restrictions, not warnings.
6. **Unknown Restaurant & Future Start Date**:
   Unknown restaurant is a blank string pending draft (`""`), not a rejection. Future `startDate` is unrepresentable in the current schema and requires blocking review before publishing as currently valid.
